# FMV-with-FMI-integration
This repository was cloned from the FMV Community Edition at the master level: https://github.com/functionalresonance/FMV_Community_Edition

The **FMI-Interpreter** branch of this project was used for development to add the FMI functionality to the FMV application. The FMI was developed as a separate software tool (https://functionalresonance.com/the-fram-model-interpreter.html) and consequently integrated into the paid (Pro) version of the FMV. This has now been pushed back and made available as the standard public functionality in the FMV Community Edition, and matches the Progressive Web App available at [https://functionalresonance.github.io/FMV_Community_Edition/](https://functionalresonance.github.io/FMV_Community_Edition/)

The **FMV-Analysis** branch was in development to add remaining Pro features from the older versions of the FMV, such as Metadata and equation calculations. This is now complete.

The next development cycle is the **FMV-Analysis-BBN** branch.

While under development, this private repository and pre-release version of the FMV is available as a sponsorship tier.

A working version of the latest test build is available here: [https://functionalresonance.github.io/FMV_Community_Edition/](https://functionalresonance.github.io/FMV_Community_Edition/)  
This version now includes Metadata and Equations, an extension to the FMI that allows for experimentation or simulation of different quantification methods.
